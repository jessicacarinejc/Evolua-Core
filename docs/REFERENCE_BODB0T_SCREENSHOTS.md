# Referências funcionais recebidas para configuração de treino

As telas de referência enviadas pela usuária foram usadas apenas para levantar requisitos funcionais. O Evolua Core deve manter identidade visual e textos próprios.

Recursos identificados para evolução do produto:

- objetivos múltiplos e específicos por modalidade;
- métricas corporais e dados de saúde;
- preferências alimentares, alergias e metas nutricionais;
- equipamentos disponíveis;
- preferências de exercícios;
- cronograma de treino;
- evolução adaptativa;
- testes de preparo físico;
- superséries e circuitos;
- atenção a articulações e regiões sensíveis;
- avaliações de recuperação;
- orientação vocal durante o treino;
- configuração de músculos/grupos musculares;
- preferências gerais do aplicativo.

A implementação deve priorizar segurança, clareza e personalização, sem copiar interface, marca, ícones, textos ou ativos de terceiros.
